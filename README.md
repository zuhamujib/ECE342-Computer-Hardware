# ECE342-Computer-Hardware
The labs use the STM32 NUCLEO-F446ZE. This course is primarily about the design and use of embedded systems. The main topics covered are:

Introduction to hardware architecture of embedded systems 
Numeric representation and arithmetic circuits: Fixed point and IEEE 754 floating point representation.
Off-chip peripherals and communication protocols.
On-chip and off-chip buses. 
Choice of processor in the design of embedded systems.
Memory types, interfacing and direct memory access
Finite state machines and the algorithmic state machine representation and Timing analysis.
